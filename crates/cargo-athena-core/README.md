# cargo-athena-core

[![crates.io](https://img.shields.io/crates/v/cargo-athena-core.svg)](https://crates.io/crates/cargo-athena-core)

The runtime behind [`cargo-athena`](https://crates.io/crates/cargo-athena):
the `Template` trait, the entrypoint-closure walk, multi-doc YAML
emission, `BuildCtx`, and the `host!` / artifact-port machinery.

This is an internal crate — generated code targets it through the
facade. Depend on **[`cargo-athena`](https://crates.io/crates/cargo-athena)**
instead.
